ShelterType 0.7 — Windows 原生打字练习

启动
从 GitHub Release 下载 ShelterType-win-x64.zip，完整解压到可写目录，然后双击 ShelterType.exe。
支持 Windows 10/11 x64，包内自带 .NET 8 Windows Desktop 运行时，无需单独安装。
请勿直接在 ZIP 内启动，也不要只复制一个 EXE。移动程序时保留整个文件夹。

随附五笔86/98、英文、中文、拼音和入门指法课程，共721门（不含个人生成的巩固课程）。

更新
启动后约5秒检查 GitHub 正式版本，自动检查最多每24小时一次。没有网络时仍可正常练习。
发现新版后以界面通知提醒，不会在练习中静默替换程序。点击下载并更新后，程序自动下载、核对 SHA-256、保存记录、退出、替换文件并重新启动。
更新器保留 UserData 中的练习进度与统计，替换失败会尝试从本次备份恢复。
设置中可以关闭自动检查，也可以随时手动检查。只有正式版本才参与检测；草稿与预发布不会提示。
更新来自 https://github.com/jasonshelter0/ShelterType/releases ，不上传练习文章、按键记录或个人统计。
SHA-256 校验用于验证下载完整性，不等同于代码签名。当前构建未作 Windows Authenticode 签名。

个人数据
UserData 文件夹保存设置、逐课进度、测速、统计和热力图。备份时复制整个 UserData 文件夹。
从以前的 TypeEasy Next 测试版迁移：先关闭旧程序，将旧 app\UserData 复制到新 ShelterType.exe 旁边，再启动新版。
课程 ID 和原文保持兼容，已有课程进度可以继续；不要把两份同时运行的程序指向同一 UserData。
新版本发布包不含任何用户记录。不要把自己练习过的文件夹重新打包当作官方发行包。

快速测试（约5分钟）
1. 启动后打开 设置 → 关于，确认品牌为 ShelterType、版本为0.7.0。检查有五笔、英文、中文三个类别。
2. 在英文入门指法课输入几键，观察正方形键帽、五色手指与目标键。收起侧栏，按 F11 专注，再按 Esc 退出。
3. 选择五笔86版二级简码，完成几项并在某项只输入一个字母，关闭再启动，确认恢复到同一课程和项内位置。
4. 在设置切换 English、Français、简体中文，确认界面即时变化、输入位置保留。切换深色/浅色也不应丢进度。
5. 故意错几键，再打开统计。切换键盘的输入频次、错误次数、错误率、常见混淆和上下文关联，点击着色按键查看计数。没有样本时应显示灰色。
6. 打开年度日历，悬停今天查看练习分钟和计数。进入文章历史，查看有记录的文章，比较连续/分段背景与错误下划线。
7. 进行一次1分钟测速，第一键开始计时；结束后查看速度趋势和本篇热力图。中止测试不应进入完整测试趋势。
8. 在设置手动检查更新。当前正式版相同应显示已是最新版本；断网应显示检查失败而不阻止练习。首次正式发布只有0.7.0，实际新版提示须等后续更高正式版本发布后出现。

统计口径
普通练习速度为正确输入次数/实际练习分钟，退格后重打也计入；限时测速为最终净前进字符数/测试分钟。
两者均含空格和标点；英文等效词/分按每5字符折算1词。正确率为正确输入/(正确输入+错误输入)。
每日与文章热力图仅展示实际记录，不补造旧日期或未练位置。文章速度按近期有效耗时中位数着色；首键、恢复后的首键、超过5秒停顿不计为有效逐字耗时。
连续背景只平滑边界显示，不平均修改原始记录。中文输入法一次提交多字的耗时为估算，不推断候选词操作和物理按键。
上下文统计显示错误与目标前后文的关联，使用输入机会作分母；样本不足会明确提示，不能据此断言错误的原因。

常用操作
设置：主题、语言、侧栏、键盘、手指、课程提示、成绩显示、更新、教学图、指法演示、错键巩固和重新开始。
课程目录：可选择自己的 KINGSOFT、Data 或兼容资料目录。新版随附课程正常时无需另选。
错键巩固生成单独课程，保留原课进度。重新开始需确认，只重置当前课，不删除全部历史。
中文文章使用系统输入法；五笔和拼音编码课直接输入程序要求的字母。五笔每项通常以空格确认。
键盘采用 QWERTY 布局，语言设置不把原文翻译成英文或法文，也未增加 AZERTY 布局。
练习进度、统计和分析都在本机完成。除更新检查和用户发起的下载外，不需要网络服务。
